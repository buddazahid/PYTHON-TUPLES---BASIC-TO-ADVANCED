# Python Tuples - Basic to Advanced

This repository contains a single Python tutorial script that demonstrates how to work with tuples in Python. It covers tuple creation, accessing values, immutability, tuple methods, type conversion, tuple unpacking, and real-world examples.

## What is included

The script `PYTHON TUPLES - BASIC TO ADVANCED.py` includes examples for:

- Creating tuples
- Accessing tuple elements
- Checking tuple length
- Working with mixed data types in tuples
- Creating single-value tuples
- Iterating through tuples
- Checking if an element exists in a tuple
- Tuple slicing and reversing
- Using `count()` and `index()` methods
- Concatenating and repeating tuples
- Nested tuples
- Tuple unpacking and extended unpacking
- Converting between lists and tuples
- Using built-in functions: `min()`, `max()`, `sum()`, `sorted()`, `tuple()`
- Real-world tuple usage examples like student records

## How to run

1. Make sure you have Python installed.
2. Open a terminal in this repository folder.
3. Run:

```bash
python "PYTHON TUPLES - BASIC TO ADVANCED.py"
```

## Why this is useful

Tuples are immutable ordered collections in Python. They are useful for storing fixed groups of values, data records, and cases where immutability and performance matter.

## Notes

- Tuples are ordered and allow duplicate values.
- Tuples are immutable, so their contents cannot be changed after creation.
- Use tuples for fixed-size collections of related values.
